## 👨‍💻 Sobre el proyecto

Mi portfolio personal es un espacio diseñado para presentar mis proyectos, habilidades técnicas y mi evolución como desarrollador de software.

Soy Analista de Sistemas y estudiante de Desarrollo Full Stack. Me interesa transformar problemas en soluciones digitales claras, funcionales y pensadas para las personas.

El objetivo de este proyecto es mostrar mi trabajo, compartir las tecnologías que utilizo y facilitar el contacto con profesionales y equipos de desarrollo.

## 📸 Preview



## ✨ Características

- **Diseño visual:** interfaz oscura con acentos verde lima, tipografías modernas y una estética inspirada en entornos de desarrollo.
- **Navegación interactiva:** cabecera fija, indicador de progreso de lectura y secciones activas.
- **Presentación dinámica:** animación de nombre, textos y elementos visuales.
- **Code Preview:** tarjeta interactiva con fragmentos de código, pestañas JavaScript/JSX y función para copiar.
- **Proyectos destacados:** presentación de HUMO y Rumbo Sur mediante ventanas de detalle.
- **Microinteracciones:** cursor personalizado, efectos magnéticos, iluminación dinámica y animaciones al desplazarse.
- **Estadísticas animadas:** contadores que muestran información del portfolio.
- **Formulario de contacto:** validación de campos y generación de un correo con el mensaje preparado.
- **Diseño responsive:** adaptación a diferentes tamaños de pantalla.
- **Accesibilidad:** soporte para la preferencia de sistema `prefers-reduced-motion`, desactivando las animaciones cuando corresponde.

## 🚀 Proyectos destacados

### 🍔 HUMO

Sitio web para una hamburguesería, desarrollado con una experiencia interactiva de compra.

**Funcionalidades principales:**

- Menú dinámico cargado desde archivos JSON.
- Configurador personalizado de hamburguesas.
- Carrito de compras.
- Cálculo automático de subtotales y totales.
- Generación de pedidos mediante WhatsApp.

**Tecnologías:** JavaScript, Bootstrap 5 y Sass.

[Ver código fuente](proyectos/CTM)

### ✈️ Rumbo Sur

Aplicación web para una agencia de viajes, orientada a la exploración y gestión de paquetes turísticos.

**Funcionalidades principales:**

- Catálogo de paquetes turísticos.
- Cotizador de viajes.
- Carrito de compras.
- Gestión de reservas.

**Tecnologías:** React 19, TanStack Start, Tailwind CSS y Sass.

[Ver código fuente](proyectos/RumboSur)

La versión estática de demostración se encuentra en `proyectos/RumboSur/demo`.

## 💻 Instalación y ejecución local

El portfolio principal está desarrollado con HTML, CSS y JavaScript, por lo que no requiere un proceso de compilación para ejecutarse.

**1. Clonar el repositorio**

```bash
git clone https://github.com/Facundo-RC/Portfolio.git
```

**2. Ingresar al directorio**

```bash
cd Portfolio
```

**3. Ejecutar el proyecto**

Abrir `index.html` en el navegador.

También se puede utilizar la extensión Live Server de Visual Studio Code para trabajar con recarga automática durante el desarrollo.
